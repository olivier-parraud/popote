# Biscuit

Tes repas de la semaine dans ton budget : menus variés (classique ou batch cooking), liste de courses chiffrée et mode magasin, scan du ticket pour mettre les prix à jour, idées pour ce soir, mode cuisine illustré pas à pas et plus de 300 recettes de 15 cuisines.

Ouvre https://olivier-parraud.github.io/popote/ sur ton téléphone, puis « Partager » → « Sur l'écran d'accueil ».

Photos des plats : Wikipédia / Wikimedia Commons (auteur et licence affichés dans chaque recette). Logos des enseignes chargés depuis leur site.
