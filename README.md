# Popote

Tes repas de la semaine dans ton budget : menus variés, liste de courses chiffrée, idées pour ce soir et 200 recettes.

Ouvre https://olivier-parraud.github.io/popote/ sur ton téléphone, puis « Ajouter à l’écran d’accueil ».

Photos des plats : Wikipédia / Wikimedia Commons (auteur et licence affichés dans chaque recette).
